# tapora-proto-kit · nhánh đo

Nhánh `measure` chỉ chứa bộ đo chi phí của các skill (`measure-kit/`): script đọc transcript, thư mục bắt đầu cố định, prompt của các phiên đo và kết quả. **Không merge nhánh này vào `main`**, và không đưa code skill vào đây.

- Code skill đo theo commit: lấy ra một worktree tạm ở đúng commit cần đo, rồi trỏ `SKILLS` vào đó. Cách làm và lệnh chuẩn bị máy: `measure-kit/README.md`, mục *Nhánh `measure` và cách lấy bản skill*.
- Kit và hướng dẫn dùng skill: nhánh `main`.
